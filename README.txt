SAMRAT AI STUDIO — PWA package

Files:
- index.html: app
- manifest.json: install metadata
- sw.js: offline cache service worker
- icon-192.png and icon-512.png: app icons

Important:
A PWA must be hosted on an HTTPS website (or localhost) before Chrome can offer Install / Add to Home Screen.
Opening index.html directly from Downloads is not enough for PWA installation.
This package does not add live AI services; AI chat/image/video/PDF features still need a secure backend/API connection.
